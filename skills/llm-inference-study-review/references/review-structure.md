# Review structure for learning topics

Good review outputs should answer:

1. 这个主题到底在解决什么问题？
2. 核心对象 / 核心路径是什么？
3. 为什么这样设计，而不是别的方式？
4. 这个点和当前 Roadmap Phase / 能力 Pillar 的关系是什么？
5. 当前真正没想明白的地方是什么？

Preferred output pattern:
- problem
- model / mechanism / system role
- tradeoff
- current understanding
- open questions
- next move
