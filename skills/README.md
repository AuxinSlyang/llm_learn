# skills

这是 `llm-learner`（具身智能 / 机器人系统 / AI Infra 学习助手）专属的 workspace skills 目录。

`skills/` 是当前 workspace 的主动工作流入口，用来定义 Codex 如何协助阅读、复盘、实验记录、日计划、周复盘和知识整理。

约定：
- 只放阅读、复盘、实验记录、知识整理相关 skills
- 不放平台管理、业务开发、股票跟踪类 skills
- 新增 skill 时，目录结构应为 `skills/<skill-name>/SKILL.md`
- 长期知识内容不沉淀在 skills 里，skills 只描述“如何工作”；学习成果应回到 `LLM_Learn/`
- `LLM_Learn/10_Workflows/skills/` 属于历史 / 过渡副本，后续新增或维护优先以顶层 `skills/` 为准
