# LLM_Learn workspace layout

Key directories:
- `01_DailyNotes/`: today's time, tasks, blockers, carry-over
- `02_WeeklyNotes/`: weekly main line, minimum completion line, weekly tasks
- `07_MonthlyPlans/`: monthly theme, minimum line, key outputs
- `90_Plans/`: annual goals and roadmaps
- `03_Projects/`: project-specific notes and experiments
- `04_Reference/`: papers, links, code snippets
- `08_Insights/`: staged insights and route corrections
- `10_Workflows/`: workflow specs and scripts

Question hierarchy:
- Annual: 我要去哪
- Monthly: 这个月重点是什么
- Weekly: 这周怎么做
- Daily: 今天做什么
