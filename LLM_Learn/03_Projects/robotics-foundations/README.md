# Robotics Foundations

## 定位

这个项目是机器人系统学习的总入口，用来承接从 `LLM / AI Infra` 视角转向 `机器人足球 / 具身智能系统` 过程中必须补齐的基础能力。

它不替代 `modern-robotics/`。`modern-robotics/` 更偏教材专题；这里负责维护更上位的系统地图、学习顺序、模块关系和后续实验入口。

## 核心问题

- 一个机器人足球系统由哪些模块组成？
- 感知、定位、规划、控制、通信、仿真、部署分别解决什么问题？
- `Modern Robotics` 里的运动学、动力学、控制知识应该接到系统里的哪一层？
- AI / LLM / 多模态模型应该作为机器人系统中的哪类能力，而不是泛泛“加 AI”？
- 后续如果做最小实验，应该先从仿真、感知、控制还是系统集成切入？

## 子线

### 1. 机器人系统总图

- 机器人足球系统模块拆解
- 单机器人闭环：感知 -> 状态估计 -> 决策 / 规划 -> 控制 -> 执行
- 多机器人闭环：通信、角色分工、协作、team-level evaluation

### 2. Modern Robotics

- 刚体运动表示
- 正运动学 / 逆运动学
- 雅可比
- 动力学基础
- 轨迹生成与控制

专题材料放在 `../modern-robotics/`。

### 3. 控制 / 规划 / 仿真

- 控制基础：反馈、稳定性、轨迹跟踪
- 规划基础：路径规划、运动规划、行为决策
- 仿真基础：从 toy simulation 到可重复实验

### 4. ROS2 / 机器人软件栈

- 节点、话题、服务、动作
- 传感器 / 执行器抽象
- 系统集成与调试
- 和仿真环境的连接

### 5. AI / LLM 支撑线

- 视觉感知与多模态理解
- 高层任务规划与策略生成
- agent runtime / tool use / system orchestration
- 模型部署、延迟、吞吐、边缘推理与 observability

## 与现有项目的关系

- `modern-robotics/`：机器人学教材专题
- `nanogpt-from-scratch/`：LLM / GPT 基础，服务于后续 embodied AI 的模型能力理解
- `makemore/`、`micrograd/`：AI 基础补强，服务于长期模型与训练直觉

## 不做什么

- 不把机器人线变成资料收集清单
- 不在基础地图未建立前直接追复杂仿真或大工程
- 不把 AI / LLM 当成机器人系统的全部
- 不把控制、运动学、系统集成这些硬基础跳过去
