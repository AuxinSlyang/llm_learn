## 在本项目里的定位

这是 `SO-ARM101 + LeRobot` 首闭环的第一个实操教程入口，用来指导：

```text
开箱清点
-> 机械装配
-> 端口 / 电机 ID
-> calibration
-> teleoperation
-> record
-> replay
-> train / eval
```

本教程优先级高于继续泛读 VLA 论文。论文阅读只服务教程中遇到的接口问题：`observation / action / dataset / policy / eval / runtime`。

## 当前补充采购判断

已补充：

- USB 摄像头：用于 LeRobot observation image 和后续数据采集。
- 多功能螺丝刀：用于安全装配，避免滑丝和临时工具损坏结构件。
- 万用表：用于供电、电压、线材连通性和异常排查。

已核对教程：

- `第零步：买买买` 明确包含 SO-ARM101 套件、腕部 USB 摄像头、电动螺丝刀这三类采购入口。
- `开箱清点` 显示套件应包含两个盒子：舵机和配件盒、3D 打印件盒；并提醒拆除 3D 打印件残留支撑，尤其检查孔、洞、槽、网格，否则后续螺丝可能拧不进去。
- `第六步：连接摄像头并遥操作` 和 `第七步：采集数据集-真机` 都给了一个摄像头和两个摄像头两套命令。一个 `front` 摄像头足够进入第一闭环；两个摄像头是 `front + side` 的增强配置。
- `采集数据集注意事项` 提醒：主动臂不应出现在画面中。第一阶段摆放摄像头时优先保证 follower、任务物体和操作区域可见。
- 万用表不是教程列出的必需采购，但作为供电、电压和线材连通性排查工具，适合保留。

当前判断：第一阶段暂时足够，不继续追加大件采购；下一步重点是清点、去支撑、分拣和安全装配。

暂不购买：

- Jetson Orin / Thor：首闭环还没有暴露端侧算力瓶颈。
- RealSense / 深度相机：第一版任务先用普通 USB RGB 摄像头。
- 高端夹爪 / 力控传感器：第一版任务先控制复杂度。
- 3D 打印机：现成打印件已到，打印机不是首闭环依赖。
- 更多摄像头：教程支持多摄，但第一阶段先用单摄像头跑通 record / replay，再决定是否补第二视角。

## 本项目裁剪后的执行顺序

1. 完成剩余物料清点：控制板、线材、电源、螺丝、3D 打印件、摄像头、工具。
2. 不通电预分拣 leader / follower 零件和舵机。
3. 等螺丝刀到位后，按 `开箱清点 -> 准备舵机 -> 组装从动臂 -> 组装主动臂 -> 调试检查机械臂` 走完装配。
4. 在 Mac 上按对应章节完成环境安装、串口端口识别、calibration。
5. 先做无摄像头 teleop，再接 USB 摄像头做带 observation 的 teleop。
6. 采集少量真机数据，先完成回看/回放，再考虑上传 Hugging Face。
7. 训练阶段只把 `ACT（推荐入门）` 作为第一目标；SmolVLA / pi0 / Diffusion 作为后续扩展。
8. 推理阶段先做 `ACT`，再看 SmolVLA；DGX Spark / RDK S100 等硬件推理平台暂不进入首闭环。
