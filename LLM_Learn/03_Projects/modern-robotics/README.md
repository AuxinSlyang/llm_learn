# Modern Robotics

## 定位

这个目录用于沉淀《Modern Robotics》相关的系统化学习内容，服务于当前“具身智能 / 机器人系统 / 机器人足球”主线。

## 当前内容

- `materials/Modern Robotics.pdf`：原始教材 PDF

## 后续建议结构

- `materials/`：原始资料（PDF、配套讲义、习题）
- `notes/`：章节阅读笔记
- `insights/`：关键概念提炼、跨章节总结、和当前主线的关联
- `experiments/`：若后续有配套代码、运动学/动力学小实验，可放这里

## 建议学习路径

1. 先快速扫一遍目录，建立全书地图
2. 优先读与机器人系统主线强相关的部分：
   - 刚体运动表示
   - 正运动学 / 逆运动学
   - 雅可比
   - 动力学基础
   - 轨迹生成与控制
3. 每读完一章，沉淀：
   - 这章解决什么问题
   - 核心公式 / 概念是什么
   - 和机器人足球 / 具身智能系统有什么关系
   - 后续是否需要代码验证
