# makemore 阶段三：CNN / WaveNet

## 补充：第三集前置训练段里的 Batch Normalization takeaway

在正式进入 `CNN / WaveNet` 之前，`makemore` 第三集前半段其实先花了一段时间处理 **更深 MLP 的训练稳定性问题**。这一段的核心不是新模型结构，而是：

> 为什么更深的网络会变难训练，以及怎样把网络内部的激活分布拉回更适合优化的范围。

### 这一段到底在解决什么问题

如果没有 `BatchNorm`，隐藏层的 pre-activation（例如 `hpreact`）在训练过程中可能会：

- 尺度越来越不合适
- 均值发生偏移
- 进入 `tanh` 的饱和区

一旦很多神经元进入饱和区：

- `tanh` 输出会靠近 `-1` 或 `1`
- 导数会变小
- 梯度传播变差
- 训练变慢、变差、变不稳定

所以 `BatchNorm` 的核心目标不是“防止某次 loss 爆炸”，而是：

> **让隐藏层激活保持在更适合训练的尺度上，改善训练动力学。**

### BatchNorm 在做什么

设某层输出：

```python
hpreact = embcat @ W1
```

如果：

```python
hpreact.shape = (N, n_hidden)
```

可以理解成：

- `N`：batch 内样本数
- `n_hidden`：隐藏层维度
- 每一列：一个 hidden neuron / 一个 feature

`BatchNorm` 做的是：

> **对每个 feature（当前阶段可以理解成每个 neuron）在当前 batch 上单独计算 mean 和 std，然后做标准化。**

形式上：

\[
\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}
\]

它的目标不是：

- 把值强行压到 `[-1, 1]`
- 保证变成高斯分布

而是：

> **让每个 feature 的激活落在均值接近 0、标准差接近 1 的尺度附近。**

### 为什么这对 tanh 有帮助

`tanh` 在输入过大或过小时会饱和。

也就是说：

- 输入太大 → `tanh(x)` 接近 `1`
- 输入太小 → `tanh(x)` 接近 `-1`
- 两端区域导数接近 `0`

于是网络就会出现：

- 激活还有值
- 但参数更新越来越不敏感
- 梯度回传效率变差

所以 `BatchNorm` 更准确的作用是：

> **让更多激活停留在 `tanh` 比较敏感的区域，而不是大面积挤在饱和区。**

### `bngain` 和 `bnbias` 的意义

标准化之后，代码里通常还会加两个可学习参数：

- `bngain`（相当于 `gamma`）
- `bnbias`（相当于 `beta`）

形式上就是：

\[
y = \gamma \hat{x} + \beta
\]

这表示：

- 前面先把分布整理到一个更利于训练的状态
- 后面再把“尺度”和“偏移”的自由度交还给模型自己学习

因此：

> **BatchNorm 改善了优化条件，但没有剥夺模型表达能力。**

### feature 是什么

在当前 `makemore` 的 MLP 场景里，`feature` 可以先理解成：

> **这一层输出向量里的一个维度，也就是一个 neuron 对应的一列输出。**

所以如果：

```python
hpreact.shape = (32, 200)
```

就表示：

- 32 个样本
- 200 个 hidden features / neurons

`BatchNorm` 是对这 200 列分别算统计量，而不是把整个层所有值混在一起只算一个总均值和总标准差。

### BN 让 batch 内样本发生了耦合

这是一个很值得记住的 insight。

没有 BN 时：

- 一个样本的前向结果只由它自己决定
- 同 batch 的其他样本不会直接影响它

有了 BN 之后：

- 当前样本会使用 batch 的 mean/std 做标准化
- 而 batch 的 mean/std 是所有样本一起算出来的

这意味着：

> **一个样本的输出会受到同 batch 其他样本的影响。**

这也是 BN 除了“数值标准化”之外一个很有意思的性质：

- 它引入了 batch 内样本之间的耦合
- 往往带来一些正则化效果和训练噪声
- 也解释了为什么它对 batch size 比较敏感

### 训练时和推理时为什么不同

训练时可以直接使用当前 batch 的统计量：

- `batch_mean`
- `batch_std`

但推理时通常不能依赖当前输入临时算 batch 统计量，因此会使用训练过程中累计得到的：

- `running_mean`
- `running_std` / `running_var`

这里要注意：

> **running mean/std 通常是每个 feature 一组，不是整层只有一个数。**

例如：

```python
hpreact.shape = (32, 200)
```

则通常会有：

```python
running_mean.shape = (1, 200)
running_std.shape = (1, 200)
```

也就是每个 neuron 都维护自己的统计量。

### 这一段最该记住的 insight

`BatchNorm` 最重要的价值，不只是一个公式，而是建立下面这个意识：

> **训练神经网络时，不只是参数本身重要，网络内部激活的中心、尺度和分布状态也同样重要。**

这也是后面继续理解更复杂网络训练稳定性的基础。

### 一句话收口

> **BatchNorm 的本质，是通过控制隐藏层激活的中心和尺度，改善深层网络的训练动力学。**

## 这一阶段最重要的问题

从 `MLP` 进入 `CNN / WaveNet`，最核心不是“又多了一种网络”，而是：

> 当上下文变长时，能不能不要继续用 `fixed window + concat` 的方式硬吃整段输入，
> 而是换一种更结构化的方式去建模序列？

---

## 为什么 `MLP` 不够

`MLP` 阶段已经解决了：

- 不再只看一个 token
- 可以看固定长度上下文
- 通过 `embedding + hidden layer + nonlinearity` 学到一定泛化能力

但它也有明显限制：

1. **上下文是固定窗口**  
   想看更长历史，通常只能直接增大 `block size`。

2. **输入组织方式比较僵硬**  
   先把所有位置的 embedding `concat` 成一个长向量，再整体送进网络。

3. **扩长上下文成本不自然**  
   上下文一变长，输入维度和参数规模都会跟着变大。

4. **不是层次化处理序列**  
   它更像“整块看”，而不是先抓局部模式，再逐层组合。

一句话总结：

> `MLP` 的问题不只是 fixed input，而是 `fixed window + flatten + 整体处理` 这套方式在长序列上比较僵硬。

---

## `CNN` 的直觉理解

`CNN` 也是神经网络，但它处理输入的方式和 `MLP` 不同。

### `MLP`

- 把上下文整体摊平
- 一次性整体判断

### `CNN`

- 保留序列结构
- 先看局部窗口
- 学局部模式
- 再通过多层把小模式组合成更大模式

所以可以先把 `CNN` 理解成：

> **把长上下文化整为零，先学子模式，再逐层组合成更大模式。**

这就是它相对 `MLP` 的核心升级。

---

## `CNN` 为什么能处理更长上下文

关键在于：

- 第一层看原始输入中的局部片段
- 第二层看第一层提出来的局部特征
- 第三层再看更高层特征

所以虽然每一层都只看局部，但：

> 更高层看到的“局部”，其实已经是低层总结过的一小段输入。

因此层数一深，模型最终能覆盖的原始输入范围就会变大。

---

## 什么是感受野（Receptive Field）

对当前阶段，可以直接理解成：

> **模型在预测当前位置时，最终最多能看到多长的历史上下文。**

也可以说：

> 某个位置的输出，最终会受到多大范围输入的影响。

`CNN` 的层数越多，通常感受野越大。

---

## 普通 `CNN` 的问题

虽然普通 `CNN` 比 `MLP` 更结构化，但它还有一个问题：

> **感受野扩张太慢。**

如果是普通连续卷积：

- 每加一层，通常只比上一层多看到一点点
- 想看很长的历史，就可能需要很多很多层

这会带来：

- 网络很深
- 训练更难
- 成本更高
- 长序列建模不够高效

一句话总结：

> 普通 `CNN` 解决了 `MLP` 的僵硬问题，但在长序列场景里，感受野长得太慢。

---

## `WaveNet` 的关键改进：Dilated Convolution

`WaveNet` 延续了卷积建模思路，但做了一个关键改进：

> **用 dilated convolution（空洞 / 膨胀卷积）更快扩大感受野。**

### 直觉

普通卷积：

- 看紧挨着的邻居
- 像小步往前挪

dilated convolution：

- 中间隔着一些位置去看
- 像跳步往前看

所以它不是不要近邻，而是：

> **避免每一层都只在近邻附近慢慢扩张。**

更准确地说：

- 底层保留近邻信息
- 更高层更快把远处历史接进来
- 多层在不同尺度上建模

一句话总结：

> `dilation` 的作用是在保留近邻建模的前提下，更高效地扩大感受野。

---

## 从 `MLP -> CNN / WaveNet` 的升级逻辑

可以压成下面这条主线：

### `Bigram`

- 只能看非常短的上下文
- 更接近统计计数

### `MLP`

- 能看固定窗口
- `embedding + nonlinearity`
- 比 `Bigram` 更有泛化能力
- 但 `fixed window + concat` 很僵硬

### `CNN`

- 先学局部模式
- 再逐层组合
- 比 `MLP` 更结构化地处理序列

### `WaveNet`

- 保留卷积建模思路
- 用 `dilated convolution` 更快扩大感受野
- 更适合长序列自回归建模

---

## 当前阶段最值得记住的 8 句话

1. `MLP` 和 `CNN` 都是神经网络。
2. `MLP` 更像把固定窗口摊平后整体处理。
3. `CNN` 更像先抓局部模式，再逐层组合成更大模式。
4. `CNN` 的高层不是直接看原始输入，而是看低层提取的局部特征。
5. 感受野就是当前预测最多能看到多长的历史上下文。
6. 普通 `CNN` 的问题是感受野扩张太慢。
7. `WaveNet` 用 `dilation` 让同样层数下看到更远的历史。
8. `dilation` 不是不要近邻，而是避免每一层都只重复处理近邻。

---

## 一句话收口

这一阶段最重要的不是记住一堆新术语，而是明确：

> `MLP` 是固定窗口整体吃，`CNN` 是化整为零逐层看，`WaveNet` 是让这种逐层看不要只困在近邻。
