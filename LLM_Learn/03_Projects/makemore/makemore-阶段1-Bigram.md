# makemore 阶段一：Bigram

## 阶段定位

这是 `makemore` 学习主线里的第一阶段。

这一阶段的任务，不是追求复杂模型，而是用最小的字符级语言模型，把下面这条主线先彻底讲清楚：

```text
token
-> logits
-> probs
-> loss
-> backward / update
-> generate
```

如果说后面的 `MLP / RNN / Transformer` 都是在不断升级模型能力，那么 `Bigram` 阶段真正提供的是：

> 语言模型训练与生成的最小闭环。

---

## 这一阶段到底在解决什么问题

阶段一最核心的问题其实很朴素：

> 给定当前 token，怎样预测下一个 token？

也就是学习：

\[
P(ch_2 \mid ch_1)
\]

在字符级名字生成任务里，这意味着：

- 已知当前字符
- 预测下一个字符的概率分布
- 按这个分布不断生成，直到结束符 `.`

所以 `Bigram` 阶段的重点不在“模型有多强”，而在：

> 先把 language model 的基本任务形式、训练形式和生成形式搭起来。

---

## 这一阶段最重要的结论

### 1. `Bigram` 本质上就是一个条件概率表 / 词表权重学习

你现在的总结是对的：

> `Bigram` 本质上就是一个词表级别的权重学习，没什么特别神秘的。

更准确地说，它可以有两种等价视角：

#### 视角 A：统计 bigram

直接数频次：

- 当前字符是 `a` 时，下一个字符出现 `b/c/d/...` 的次数分别是多少
- 再归一化成条件概率分布

得到的是：

\[
P(ch_2 \mid ch_1)
\]

#### 视角 B：神经网络 bigram

用 one-hot 当前字符 `xenc` 去乘一个参数矩阵 `W`：

\[
logits = xenc @ W
\]

这里 `W` 的每一行，其实就对应：

> 当前字符固定时，对所有下一个字符的一组打分权重。

因此，神经网络 bigram 的本质也很接近“查表”，只是这个表不是直接数出来的，而是通过训练学出来的。

---

### 2. `xenc @ W` 的本质，就是“取出当前 token 对应的一行分数”

这是阶段一最值得吃透的一点。

因为输入是 one-hot，`xenc @ W` 的效果并不神秘，本质上就是：

> 根据当前 token 的 id，从 `W` 里取出对应那一行。

所以如果：

- 词表大小是 `V`
- `W` 的形状是 `(V, V)`

那么：

- 第一个维度表示“当前 token 是谁”
- 第二个维度表示“下一个 token 的候选是谁”

因此 `W[i, j]` 可以理解成：

> 当前 token 是 `i` 时，下一个 token 是 `j` 的原始偏好分数。

这也是为什么你会感觉：

> `Bigram` 本质就是一个词表权重矩阵的学习。

这个理解是对的，而且很重要。

---

### 3. logits 不是概率，而是原始分数

`xenc @ W` 得到的是 logits，不是概率。

logits 的特点是：

- 可以为负
- 不要求和为 1
- 只是每个候选下一个字符的原始分数

因此还需要：

```text
logits
-> exp
-> normalize
-> probs
```

最后才能得到合法的概率分布。

所以这一阶段必须讲清楚：

> 模型真正直接输出的是 logits，概率是后处理出来的。

---

### 4. `probs` 才是 next-token prediction 的真正输出

经过指数化和归一化之后，得到：

\[
P(next\ token \mid current\ token)
\]

这一步的意义是：

- 对训练：可以和真实标签比较
- 对生成：可以按分布采样下一个字符

所以语言模型的核心目标，其实始终是：

> 输出一个关于下一个 token 的概率分布。

---

### 5. 训练和生成共用同一套前向，只是后续分叉不同

这一点在阶段一已经必须建立。

#### 训练时

```text
current token
-> logits
-> probs
-> 和真实 next token 计算 loss
-> backward
-> 更新 W
```

#### 生成时

```text
current token
-> logits
-> probs
-> 按概率采样下一个 token
-> 继续下一步
```

所以这里最重要的不是把“训练”和“生成”拆成两套不同东西，而是理解：

> 它们共享同一个前向概率模型，只是在前向之后，一个拿去优化，一个拿去采样。

---

### 6. 统计 bigram 的 loss 略低于神经网络 bigram，是合理现象

这一阶段一个很有价值的判断是：

- 统计频次模型在充分对齐条件下，通常更接近 bigram 任务的 MLE 最优解
- 神经网络 bigram 虽然形式不同，但本质上仍在学同一个任务

所以如果看到：

> 统计 bigram 的 loss 略低于神经网络 bigram

这不是异常，而是符合预期的。

这说明你对“任务本质”和“模型形式”之间的关系已经开始有判断了。

---

## 阶段一真正建立起来的最小主线

这一阶段已经建立起来的最小主线，可以压成：

```text
当前 token
-> one-hot
-> xenc @ W
-> logits
-> probs
-> 
  训练：loss -> backward -> update
  生成：sample -> next token
```

这条链是整个 `makemore` 后续阶段的起点。

如果这条线讲不顺，后面的 `MLP / RNN / Transformer` 都会变成“更复杂但更糊”。

---

## 为什么说阶段一很重要，虽然它本身不复杂

`Bigram` 模型本身确实不复杂，甚至可以说有点“朴素”。

但它重要，不是因为表达能力强，而是因为它最适合讲清下面这些基础点：

1. 什么是 language model
2. 什么是 next-token prediction
3. 什么是 logits
4. 什么是 probs
5. 什么是 loss
6. 什么是训练
7. 什么是生成

也就是说：

> 阶段一的价值不在模型，而在最小闭环。

---

## `Bigram` 的局限

阶段一收口后，也要明确它为什么必须被后续阶段升级。

`Bigram` 的主要限制有两个：

### 1. 上下文太短

它只能看一个 token：

\[
P(ch_2 \mid ch_1)
\]

这导致很多更长的上下文信息根本进不来。

### 2. 泛化能力弱

它更像：

- 条件概率查表
- 词表权重学习
- 对 seen pattern 的拟合

而不是更强的模式泛化。

这也是为什么后面一定要进入：

> `Bigram -> MLP`

从单 token 条件概率，走向固定窗口上下文 + embedding + 非线性建模。

---

## 阶段一和阶段二的衔接

如果用一句话概括阶段一到阶段二的升级逻辑，就是：

> 阶段一先把“预测下一个 token”这件事讲清，阶段二再解决“只看一个 token 不够”这个问题。

也就是：

```text
阶段一：Bigram
-> 看一个 token
-> 最小训练 / 生成闭环

阶段二：MLP
-> 看固定长度上下文
-> embedding + 非线性
-> 更强的函数拟合与泛化
```

所以阶段一不是被阶段二推翻，而是被阶段二吸收。

---

## 当前阶段已经吃到的内容

基于当前这轮学习和已有总结，阶段一已经比较明确吃到的点包括：

- `Bigram` 的任务定义：学习 `P(ch2 | ch1)`
- 统计 bigram 与神经网络 bigram 的对应关系
- `xenc @ W -> logits -> probs` 的计算链
- 训练和生成在前向之后的分叉
- `W` 可以理解成词表级别的 next-token 权重表
- 统计频次模型略优于神经网络 bigram 的合理性

---

## 当前阶段最值得记住的 7 句话

1. `Bigram` 学的是 `P(ch2 | ch1)`。
2. 统计 bigram 和神经网络 bigram 本质上在做同一件事。
3. `xenc @ W` 的本质是按当前 token 取出一行 logits。
4. `W` 可以理解成一个词表到词表的 next-token 权重矩阵。
5. logits 不是概率，概率需要经过归一化得到。
6. 训练是在用真实标签更新 `W`，生成是在固定 `W` 下按概率采样。
7. 阶段一最重要的价值是建立语言模型的最小闭环，而不是模型复杂度。

---

## 当前还没必要在阶段一死磕的内容

阶段一已经足够完成收口，下面这些不值得继续在这里深挖：

- 把所有反向传播细节都硬塞在 `makemore` 里推完
- 在 `Bigram` 上纠缠过多实现边角问题
- 试图让这个模型承担长上下文建模能力

这些更适合：

- 反向传播细节 -> `micrograd`
- 更强表达能力 -> `MLP` 及后续阶段

---

## 一句话收口

阶段一 `Bigram` 最重要的，不是模型多强，而是明确：

> 语言模型可以被看成一个“根据当前 token 产生下一个 token 概率分布”的最小训练与生成闭环；而在这个阶段里，神经网络 bigram 本质上就是一个词表级别的 next-token 权重学习。
