# LLM_Learn README

本目录是 `llm-learner` 的长期学习知识库与执行系统，围绕以下目标组织：

- 短期职业目标：成长为 **具身智能系统构建者**，以具身智能软件 / Robot Learning Infra / Policy Runtime / 机器人全栈工程入口作为现实第一跳
- 长期能力目标：成长为 **机器人全栈工程师 / roboticist**，能够打通机器人本体 / 感知决策 / 运动控制 / 多机器人协作 / 语言智能 / AI Infra
- 智能子能力分层：感知智能 / 运动智能 / 决策智能 / **语言智能（LLM / 多模态）** / 协作智能；AI Infra 是让语言智能跑得起来、跑得稳的工程化底座
- 当前阶段：未来一年以 `Robot Learning Full-Stack` 为上位主线，保留 `LLM / AI Infra / Runtime` 作为 `VLA runtime / robot policy runtime / edge inference` 的系统支撑线
- 按 **年度计划 → 月计划 → 周计划 → 日记** 的节奏，持续每天推进学习
- 在不推倒重来的前提下，逐步整理、收敛、归档和去噪历史 Obsidian 内容
- 命名注意：目录名仍叫 `LLM_Learn/`（保留历史），但其内涵已升级为「具身智能长期学习系统」，不再仅限 LLM

## 当前保留骨架

- `01_DailyNotes/`：日记
- `02_WeeklyNotes/`：周计划 / 周复盘
- `03_Projects/`：项目化 / 专题化学习对象
- `07_MonthlyPlans/`：月计划与长期 roadmap
- `08_Insights/`：高价值 insight、学习总结与精加工沉淀
- `10_Workflows/`：工作流说明、命令规范、脚本入口（当前先保留，后续逐步迁入 OpenClaw 原生流程）
- `99_Templates/`：模板目录
- `.obsidian/`：知识库运行环境

## 使用原则

- 这是学习与实验知识库，不是单一软件项目仓库
- 优先复用现有结构，不随意重建一套平行体系
- 如果用户提到「今天 / 本周 / 本月 / 当前阶段」，优先先看已有 Daily / Weekly / Monthly / Plans 笔记
- 新建内容时，优先基于模板与现有目录扩展
- 对于旧内容，先 review、分类，再决定整理、归档或清理
- `LLM / 多模态` 是具身智能的语言智能子能力本身，`AI Infra` 是其工程化底座；不再以单独 LLM Infra 路线作为主叙事
- 机器人相关内容优先落在 `03_Projects/`、`07_MonthlyPlans/` 和 Daily / Weekly 执行链路中，不只停留在 roadmap 口号里
