# 月计划导航

## 当前定位

- 短期职业目标：成长为 `AI Core Storage / 高性能分布式存储工程师`，以 DeepSeek Storage / KVCache Storage / Training Data Storage 作为现实第一跳。
- 中期能力目标：进入 `LLM Inference Runtime / KVCache / serving / kernel optimization`，从存储系统走向模型推理系统。
- 长期能力目标：成长为 `机器人全栈工程师 / roboticist`，在合适时机把 AI core infra / inference runtime 能力回接到 Robot/VLA Runtime。
- 未来一年执行主线：以 `DeepSeek Storage -> KVCache -> Inference Runtime` 为上位目标，机器人 / 具身智能保留为长期 North Star 和低频探索线。
- 月计划负责回答：`这个月主攻什么、最低完成线是什么、对应哪几周`。
- 周计划继续放在 `02_WeeklyNotes/`。

## 与历史路线的关系

- 2026-03 ~ 2026-05 保留了从 LLM Infra 起步、逐步转向具身智能的真实过程。
- 2026-05-17 之后，语言智能（LLM / 多模态）重新定位为具身智能的子能力，AI Infra 是语言智能落地的工程底座。
- 2026-05-27 之后，曾短暂尝试把 `LLM Inference Infra` 作为短期职业踏板；该版本保留为历史，但不再作为当前执行依据。
- 2026-06-01 之后，Unitree JD 对齐后再次校准：`具身智能软件 / Robot Learning Infra / Policy Runtime` 成为更贴近长期目标的第一跳，详见 [[09_One_Year_Robot_Learning_Full_Stack_Roadmap]]。
- 2026-06-28 之后，根据 DeepSeek `高性能分布式存储工程师` JD 再次校准：近期第一跳改为 `AI Core Storage / DeepSeek Storage`；Unitree / Robot Learning 路线保留为长期参考，不再作为近期执行依据。
- 旧版 LLM Infra / JD1 资料归档在 `LLM_Learn/_archived/jd1-legacy/`，作为方向演化快照保留，不作为当前执行依据。
- 旧版 2026 H2 Robotics-first 月计划和 LLM Infra-only 计划都保留为历史素材，不作为当前执行依据；当前执行依据见 [[11_DeepSeek_Storage_to_Inference_to_Robot_Runtime_Roadmap]]。
