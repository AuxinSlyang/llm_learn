# 2026-05 月计划

## 本月定位

- 阶段：`短期 LLM 主线延续 + 中长期具身智能转向准备`
- 月主题：`以 nanoGPT 为主线完成 LLM 基础理解升级，同时开始搭建机器人 + CV + LLM 并存的中长期学习框架`
- 对当前阶段的意义：5 月不是立刻全面切机器人，而是先把 `nanoGPT / GPT 基础理解` 打牢，再为后续 `CV / Robotics / Embodied AI` 路线开入口

## 本月学习主线

本月采用“双层结构”：

### 主线 A（短期主线）
- `nanoGPT`
- `GPT 基础理解`
- `训练代码主链路`
- `为后续语言智能、inference / runtime / agent 工程线建地基`

### 主线 B（转向准备线）
- `机器人系统 overview`
- `CV / 控制 / ROS2 / 仿真 的全景认识`
- `机器人 + CV + LLM 并存路线的第一版框架`

## 本月主干

本月不是“继续只学 LLM”，也不是“立刻全面切机器人”。

本月真正的主干是：
- 用 `nanoGPT` 快速补强 GPT / 训练 / 模型实现直觉
- 把这条线变成未来理解 inference / runtime / agent 的基础
- 同时开始给 `机器人 + CV + LLM` 并存路线建立结构，而不是以后再临时拼接

## 本月不做什么

- 不在 5 月就强行并行展开过多机器人细分技术点
- 不把 `nanoGPT` 学习拖成无边界扩散
- 不把中长期路线只停留在口号，不落成结构化说明
- 不再把自己只定义成“单一 LLM 工程线学习者”

## 本月完成得比较扎实的标志

当下面这些条件基本满足时，可以认为 5 月推进得比较稳：
- 你能讲清 `nanoGPT` 最小训练闭环
- 你能说清它为什么是当前最合适的短期主线
- 你能说明后续为什么要补 `CV / 控制 / ROS2 / 仿真`
- 你已经把长期方向明确成 `机器人 + CV + LLM` 并存，朝 `具身智能全栈工程师` 方向发展
