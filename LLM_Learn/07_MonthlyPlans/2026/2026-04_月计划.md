# 2026-04 月计划

## 本月定位

- 阶段：`目标重构期 / 路线切换期`
- 月主题：`把长期目标从单一 LLM Infra 学习路线升级为“具身智能系统 / 机器人系统 + AI Infra 支撑”的新框架`
- 对当前阶段的意义：这不是简单换兴趣，而是把未来几年真正想做的事情前置成总目标，并重新安排已有 AI Infra 学习资产的位置

## 本月学习主线调整

从本月开始，学习路径不再只定义为：
- `Karpathy -> nano-vLLM -> CS336 -> LLM Infra`

而改成：
1. `重写长期目标与学习路线图`
2. `建立具身智能 / 机器人系统的第一版总图`
3. `明确 AI Infra / LLM inference 在新目标中的支撑定位`
4. `为接下来 2-3 个月的学习切换准备新的阶段计划`

## 为什么现在要先做这件事

当前最重要的问题已经不是“先学哪个模型系统框架”，而是：
- 我未来到底想构建什么系统？
- 机器人系统这个目标需要哪些能力模块？
- 原来已经开始积累的 LLM / inference / infra 学习线，应该怎么作为具身智能的语言智能与工程底座保留下来？

如果这一步不先做清楚，后续阅读和实验仍然会继续散。

## 本月主干

本月核心不是继续压更多模型课程，也不是继续只盯着单一模型系统框架。

本月核心是：
- 完成目标升级
- 收拢学习语义
- 建立新的主线
- 让已有 AI Infra 资产在新目标里找到位置

## 本月不做什么

- 不把“继续刷更多 inference 材料”当作唯一推进方式
- 不急着在没有总图的情况下直接开很多机器人细分技术点
- 不把兴趣转向理解成“之前学过的都作废”
- 不继续沿用“单一 LLM Infra 路线”作为唯一叙事中心

## 本月完成得比较扎实的标志

当下面这些条件基本满足时，可以认为 4 月的主线切换比较成功：
- 你能清楚说出为什么长期目标变成了“具身智能 / 机器人系统”
- 你能解释 AI Infra 为什么仍然值得保留
- 你已经把未来学习拆成机器人系统、感知决策、多机器人协作、AI Infra 支撑几条线
- 你已经知道 5 月优先该补什么，而不是继续泛泛地学
