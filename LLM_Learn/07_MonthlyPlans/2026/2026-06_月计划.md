## 2026-06-08 修订：实物首闭环优先

新的执行判断：

```text
本月第一项目不应停留在纯论文 / 纯仿真
-> 优先启动 SO-ARM101 + LeRobot 真实硬件闭环
-> LingBot-VLA 作为 walkthrough / schema mapping / VLA runtime 升级方向
-> Gymnasium/MuJoCo 作为硬件阻塞兜底线
```

原因：

- 如果第一阶段没有实物，很容易在后续 VLA / policy runtime / robot learning 深水区缺少真实系统感。
- 真实机械臂会提前暴露端口、校准、电机、摄像头、示教数据、replay、eval、failure taxonomy 等关键问题。
- 第一个月不追求 `LingBot-VLA 4B full post-training`；它太重，且没有真实 data/eval loop 时失败来源不可分解。
- 第一阶段最重要的证据是：`teleop -> dataset -> replay/train -> eval -> failure note`。

## 2026-06-11 修订：W24 后半周收束

`2026-06-11` 已完成 LeRobot 数据闭环和 ACT/ALOHA 第一轮结构化阅读。接下来几天的安排收束为：


约束：

- LLM 经典论文可以回看并沉淀，但只作为 `LLM phase 1 closure`，不重新扩成上位主线。
- 摄像头和螺丝刀未到前，不安排装配 / 通电 / 校准；硬件阻塞不是本周执行失败，等待期用于基础补课和笔记沉淀。
- CV 在硬件等待期升级为一轮 `CV Foundation Sprint`：`AlexNet -> VGG -> Inception -> ResNet -> ViT -> Vision Transformers Need Registers -> CLIP / BLIP-2 / LLaVA`；目标是服务 robot observation、VLM/VLA visual tokens、image-text alignment 和 attention interpretability，不开完整 CV 全科。

- ACT/ALOHA 是当前最贴近 LeRobot 首闭环的 robot learning 论文；实验和 ablation 可以后续读，但周日硬件优先级更高。
