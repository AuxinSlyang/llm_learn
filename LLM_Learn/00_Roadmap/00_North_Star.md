# North Star

> 这份文件回答的问题：**我最终要成为什么样的人 / 构建什么样的系统？**
> 更新频率：年级（每年年终复盘可能微调）；写于 2026-05-17。

## 一句话定位

成为通用具身智能领域有真实影响力的系统构建者——既能动手把一个机器人系统从零搭起来，也能在 robot learning / AI 方法上有自己的判断与产出，并通过开源 + 真实部署在物理世界产生可见的 impact。

## 10 年长期能力画像

5-10 年后我希望自己是这样的人：
- **能力面**：跨 Classical Robotics + AI Fundamentals + Robot Learning 三条腿都站得稳的具身智能系统构建者
- **工程面**：能从硬件抽象 → 控制 → 规划 → 感知 → 学习 → 部署打通完整 stack
- **研究面**：能识别真问题、提方法、独立推进 / 复现 / 改进 SOTA
- **影响力面**：通过开源系统 + 真实部署在领域内被看见——而不是以 paper 数为标尺
- **形态独立性**：技术身份不依赖单一公司、单一框架、单一硬件平台

## 终极方向

**通用具身智能**——能在多种形态、多种场景、多种任务下表现出智能行为的物理智能体。

不绑定单一 vertical（如纯 LLM、纯自动驾驶），而是穿过感知 / 控制 / 学习 / 决策的完整智能体能力。

## Anchor 场景

| Anchor | 角色 | 时间窗 |
|---|---|---|
| **机器人足球（11v11 长期愿景）** | 主 anchor：multi-agent + locomotion + perception + 实时闭环 | 长期 |
| **Manipulation（pick-place / dexterous）** | 验证 Robot Learning + 精细控制 | 中期 |
| **Mobile navigation in unknown env** | 验证感知 + 规划 + 自主性 | 中期 |
| **Multi-robot coordination** | 验证多智能体 + 通信 + 协作 | 长期 |

机器人足球是长期最高优先级 anchor，但不再是唯一目标——通用具身智能的全集 > 足球能 stress 到的部分。

## 我已有的底子（差异化资产）

- **嵌入式经验**：硬件抽象、底层资源管理、real-time 直觉
- **CS / 系统工程**：系统设计、cache、HBM、存储栈、分布式
- **学习能力**：长期自学、持续 track、能沉淀知识

这些是我转向具身智能的真实差异化——大多数 AI / Robot Learning 人不具备底层 / 系统 / 硬件直觉。我的目标不是变成"另一个 AI 工程师"，而是把这些底子转化成具身智能场景里别人难以替代的能力。

## 为什么是这个方向

- 具身智能是 AI 真正进入物理世界的关键场景
- 机器人这条线，硬件 + 系统 + AI 三件事同时考验，匹配我的能力栈
- 这是个 10-20 年的方向，时间维度匹配我的耐心
- 我希望做的事是"能在物理世界产生 impact"，不只是在屏幕上
- 在机器人领域，开源系统和真实产品落地是一体的——这条路径匹配我的能力定位

## 边界 / 不做什么

- 不追单点 benchmark 1% 的工程
- 不绑定单一公司 / 框架 / 硬件平台
- 不走马观花——每个学过的东西都要吃透
- 不追每月新热点——选定方向就深扎
- 不在没建立系统视角前钻细节
- 不以发 paper 为主要追求——paper 是副产物，不是目标

## 一句话回锚

> 成为具身智能领域真正能从硬件到 AI 都看得懂、都做得了的人，并通过我建造的开源系统 + 真实部署的机器人在物理世界产生可见的 impact。
