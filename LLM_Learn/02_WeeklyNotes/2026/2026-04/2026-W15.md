## Karpathy 核心学习地图

### 主干顺序

1. `micrograd`：吃透自动求导最小闭环、backward、grad accumulation、参数更新
2. `makemore`：按模型演进线学习字符级语言模型
   - `Bigram`
   - `MLP`
   - `CNN / WaveNet`
   - `RNN`
   - `LSTM`
   - `GRU`
   - `Transformer`
3. `nanoGPT`：进入更完整的 GPT 训练与实现理解
4. `tokenizer / modern GPT 细节`：补 tokenization、训练稳定性、实现细节
5. `serving / inference`：最后再回到 `prefill / decode / KV cache / TTFT / TPOT / throughput`
