## 适合当前阶段的补充读物

### 第一层：这周先读，目标是把最小推理闭环跑通
- [ ] Hugging Face `Text generation` 文档  
  https://huggingface.co/docs/transformers/llm_tutorial
- [ ] Karpathy `Let's build GPT: from scratch, in code, spelled out`  
  先看前 `60-90m`，重点只抓 `token`、`logits`、`self-attention`、`next token prediction`  
  https://www.youtube.com/watch?v=kCc8FmEb1nY
- [ ] Hugging Face blog `KV Cache from scratch in nanoVLM`  
  用来建立 `prefill / decode / KV cache` 的第一层直觉  
  https://huggingface.co/blog/kv-cache

### 第二层：Week 2-3 读，目标是把 Transformer 主流程讲清楚
- [ ] `Attention Is All You Need`  
  只先读总览、attention、multi-head attention、positional encoding，不追训练细节  
  https://arxiv.org/abs/1706.03762
- [ ] `The Annotated Transformer`  
  适合边看边对照代码，把论文公式落到实现  
  https://github.com/harvardnlp/annotated-transformer
- [ ] Sebastian Raschka `LLMs-from-scratch`  
  优先看 `ch03` 和 `ch04`，你会更容易把 attention 和最小 GPT 实现串起来  
  https://github.com/rasbt/LLMs-from-scratch

### 第三层：进入 inference / serving 视角后再读
- [ ] `Efficient Memory Management for Large Language Model Serving with PagedAttention`  
  vLLM 的代表论文，重点看 `KV cache`、`memory waste`、`throughput` 为什么改善  
  https://arxiv.org/abs/2309.06180
- [ ] vLLM `Metrics` 文档  
  用来建立 `TTFT / TPOT / queue time / prefill time / kv cache usage` 指标直觉  
  https://docs.vllm.ai/en/stable/design/metrics/
- [ ] SGLang `Benchmark and Profiling` 文档  
  用来建立 `bench_serving / profile / tracing` 的工具感  
  https://docs.sglang.io/developer_guide/benchmark_and_profiling.html
- [ ] `Awesome-ML-SYS-Tutorial` 里的 `SGLang Code Walk Through`  
  适合你后面开始看 serving 系统控制流时再用  
  https://github.com/zhaochenyang20/Awesome-ML-SYS-Tutorial

### 可选旁线：更偏工程手感，先收藏，不作为本周主线
- [ ] `llama.cpp`  
  适合在 `Mac` 上建立“推理程序长什么样”的直觉  
  https://github.com/ggml-org/llama.cpp
- [ ] `llm.c`  
  适合以后补底层实现手感，但当前阶段不要拿它替代 `transformers` 最小闭环  
  https://github.com/karpathy/llm.c

## 两周阅读顺序

### Week 1：目标是跑通最小推理闭环，不追系统细节
- [ ] Day 1：Hugging Face `Text generation` 文档  
  看什么：模型加载、tokenizer、`generate()` 最小示例  
  看到什么算完成：你能自己写出一版最小生成脚本骨架
- [ ] Day 2：Karpathy 视频前 `60-90m`  
  看什么：`token`、`embedding`、`logits`、`self-attention`、`next token prediction`  
  看到什么算完成：你能不用资料解释“模型为什么是一 token 一 token 地往后吐”
- [ ] Day 3：Hugging Face `KV Cache from scratch in nanoVLM`  
  看什么：`prefill`、`decode`、为什么缓存 KV、为什么长上下文更贵  
  看到什么算完成：你能写出 `prefill` 和 `decode` 的一句话定义
- [ ] Day 4：vLLM 文档首页 + metrics 页  
  看什么：vLLM 解决什么问题、核心指标有哪些  
  看到什么算完成：你知道 `TTFT`、`TPOT`、`KV cache usage` 是什么

### Week 2：目标是把 Transformer 主流程和 serving 视角接起来
- [ ] Day 1：`Attention Is All You Need`  
  看什么：attention、multi-head attention、positional encoding  
  看到什么算完成：你能画出 `Q/K/V -> attention -> output` 的最小链路
- [ ] Day 2：`The Annotated Transformer`  
  看什么：论文公式如何落到代码  
  看到什么算完成：你能把论文里的 attention 和实现里的 tensor shape 对上
- [ ] Day 3：`LLMs-from-scratch` 的 `ch03/ch04`  
  看什么：最小 GPT 结构和 attention 实现  
  看到什么算完成：你知道最小模型前向大概经过哪些模块
- [ ] Day 4：`PagedAttention` 论文  
  看什么：KV cache 的碎片浪费、分页思想、为什么影响吞吐  
  看到什么算完成：你能说清楚“vLLM 为什么比 naive HF serving 更像一个系统”
