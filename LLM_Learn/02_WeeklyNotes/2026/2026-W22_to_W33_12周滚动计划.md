# 2026-W22_to_W33 12 周滚动计划

> 这份文件回答的问题：**未来 12 周每周具体推进什么？**

## 12 周总目标

用 12 周完成第一段基础闭环：

```text
nanoGPT 收口
-> CS336 前置补丁
-> CS336 完整第一轮理解
-> nano-vLLM code walkthrough
-> vLLM 最小入口与 benchmark
```

核心判断：最近不急着直接进 vLLM。先把 nanoGPT 讲清楚，再用 CS336 建完整语言模型系统地图，最后用 nano-vLLM 进入推理系统代码。

## 最近 4 周细化

### W22：2026-05-25 ~ 2026-05-31

- 主线：路线修订 + nanoGPT 缺口盘点。
- 做：
  - 确认未来一年主线：LLM Inference Infra -> Robot Runtime。
  - 列 `nanoGPT` 还不能顺口讲出的 5-8 个问题。
  - 整理 `nanoGPT` 代码主链路的入口文件、函数和关键张量。
- 不做：
  - 不开 CS229 / CS231n 大课。
  - 不直接读 vLLM 大源码。

### W23：2026-06-01 ~ 2026-06-07

- 主线：nanoGPT 主链路收口 1。
- 做：
  - 讲清 `get_batch -> model(x, y) -> logits/loss -> backward -> optimizer.step`。
  - 讲清 `generate` 和 training forward 的共用与分叉。
  - 画一张 `token -> embedding -> attention -> block -> logits -> loss/generate` 图。
- 周产出：`nanoGPT 主链路总结 v0`。

### W24：2026-06-08 ~ 2026-06-14

- 主线：nanoGPT 主链路收口 2 + CS336 前置补丁。
- 做：
  - softmax / cross entropy / maximum likelihood。
  - SGD / Adam / weight decay / gradient clipping。
  - PyTorch `nn.Module` / optimizer / DataLoader / checkpoint。
  - attention shape / residual / layernorm。
  - GPU memory / FLOPs / bandwidth / batch / KV cache memory。
- 周产出：`CS336 前置补丁 checklist`。

### W25：2026-06-15 ~ 2026-06-21

- 主线：CS336 入口前半。
- 做：
  - 看 CS336 overview / tokenization / data / architecture 相关内容。
  - 每讲只回答：它解决什么问题、输入输出是什么、和 inference infra 的关系是什么。
  - 建立 `CS336 课程地图 v0`。
- 周产出：`CS336 data-tokenizer-architecture 笔记`。

## 成功标准

到 2026-W33 结束，至少满足：

- 能不用资料讲清 nanoGPT 的训练和生成主链路。
- 能讲清 CS336 从 data 到 deployment 的完整系统地图。
- 能解释为什么 training loop 和 inference serving 是不同系统问题。
- 能读懂 nano-vLLM 的主路径：request、scheduler、prefill、decode、KV cache。
- 能把 nano-vLLM 的教学版骨架对到 vLLM 的生产级问题：PagedAttention、continuous batching、metrics。

## 风险与降难

| 风险 | 降难策略 |
|---|---|
| nanoGPT 收口拖太久 | 只保主链路，不追所有实现细节 |
| CS336 作业太重 | 做取舍记录：能服务 inference infra 的才做，其余只复述 |
| 课程看完但没有系统图 | 每周必须输出一页 map，不允许只看视频 |
| 过早读 vLLM 源码 | 先 nano-vLLM，再 vLLM；生产级源码只按问题点查 |
| 机器人目标被淡化 | 每月写一次 `inference -> robot runtime` 回锚 |
