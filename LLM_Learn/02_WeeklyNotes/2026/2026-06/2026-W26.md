# Week 2026-W26 学习记录

## 本周锚点

- 日期范围：`2026-06-22 ~ 2026-06-28`
- 本周主题：`示教数据 + 第一版 policy + 真机 eval`
- 本周硬产出：`30-50 条 episode` + `ACT/BC train v0` + `10 次 eval 表` + `failure taxonomy`
- 本周完成标准：哪怕成功率很低，也要能说清失败来自硬件、数据、任务约束、视觉视角还是模型。

## 本周唯一主线

- [ ] 从真实示教数据进入第一版 policy，并完成可复盘的评估与失败分类。

## 本周最低完成线

- [ ] 固定一个任务：默认 `push-to-zone`，顺利再升级到简单 `pick-and-place`。
- [ ] 录制 30-50 条同一任务 episode；如果时间不足，至少 15-20 条并解释不足。
- [ ] 检查 LeRobot dataset 字段：`observation.images / observation.state / action / task / episode`。
- [ ] 完成一次 ACT/BC v0 训练尝试，保存命令、日志、checkpoint 或 blocker。
- [ ] 做 10 次 eval 或写出无法 eval 的明确 blocker。
- [ ] 写 failure taxonomy：抓不到、推偏、视角不稳、校准漂移、示教分布差、动作过快/过慢、模型输出异常。

## 本周 Top 3

- [ ] `数据质量`：episode 一致、视角稳定、任务边界清楚。
- [ ] `训练尝试`：ACT/BC v0 能启动，失败也要有日志。
- [ ] `真实 eval`：10 次表格 + failure taxonomy。
