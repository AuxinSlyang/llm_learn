# 2026 具身智能 / 机器人系统 / AI Infra 年度计划

> 起点假设：你目前对 `LLM inference / serving / AI infra` 有明确学习兴趣，也已经围绕这条线开始搭建知识库；但长期牵引目标已经升级为 `构建自己的机器人足球队`。  
> 当前设备：本地 `Mac` 负责知识整理、阅读、规划与文档维护，远端 `Linux / V100` 负责最小实验、benchmark、推理环境验证，并逐步承担机器人/仿真相关实操。  
> 主线目标：在 `2026` 年内完成从“单一 LLM inference 视角”到“机器人系统 + 感知决策 + AI Infra”三位一体学习框架的切换，并建立第一版具身智能学习地图与实验闭环。

## 目标定义

今年的目标不再是“尽快成为纯 LLM Inference 工程师”，而是拿到下面 4 类更上位的真实能力：

1. `系统目标能力`
   你能围绕“机器人足球队”这个真实场景，解释清楚一个完整系统需要哪些模块：感知、定位、决策、控制、多机器人协作、仿真、部署与维护。
2. `机器人基础能力`
   你能逐步建立机器人系统基础认知，包括机器人软件栈、仿真环境、基本感知链路、规划控制与系统集成的最小地图。
3. `语言智能 + 支撑 Infra 能力`
   你继续深化 `LLM / 多模态 / inference / serving / agent / runtime / GPU infra`，定位是把它们作为具身智能中的**语言智能子能力**及其工程化底座，而不是独立的转岗目标。
4. `知识沉淀与实验闭环能力`
   你能把学习内容持续沉淀成 roadmap、月/周计划、实验记录、阶段性总结与下一步判断，而不是只停留在散点阅读。

## 新的总目标

### 终极目标

- 构建一支属于自己的机器人足球队。

### 长期能力目标

- 成长为一名能够打通 `机器人系统 / 感知决策 / 多机器人协作 / AI Infra` 的具身智能系统构建者。

### 对 LLM / 语言智能 / AI Infra 的重新定位（2026-05-17 更新）

- 具身智能由多种「智能子能力」组成：感知智能、运动智能、决策智能、**语言智能**、协作智能。
- `LLM / 多模态模型` 不再是「外部支撑底座」，而是**具身智能的语言智能子能力**本身——机器人的「会说话、会理解、会被指令」部分。
- `AI Infra`（inference / serving / runtime / GPU / profiling）的定位是：让语言智能 / 多模态智能在机器人系统中跑得起来、跑得稳，是语言智能落地的工程能力线。
- 这意味着 LLM 学习不再是"为了转岗 LLM Inference 工程师"，而是为了：
  - 让未来的机器人能听懂自然语言指令
  - 让多机器人协作中有语言层的协调
  - 让高层任务分解 / 行为编排有模型基础
  - 让 agent-like 行为可以在具身系统中被组合调用

## 学习主线重构

从现在开始，学习主线建议拆成 4 条：

### 主线 1：机器人与具身智能基础（第一主线）

核心问题：
- 机器人系统由哪些核心模块组成？
- 机器人足球系统的最小闭环是什么？
- 从单机器人到多机器人系统，要补哪些基本能力？

重点内容：
- 机器人学基础
- 机器人软件栈（ROS2 等）
- 仿真环境与实机闭环概念
- 机器人足球领域结构图
- 任务分层：感知 / 规划 / 控制 / 协作

### 主线 2：感知 / 定位 / 规划 / 控制

核心问题：
- 机器人如何看到球、场地、队友、对手？
- 如何在场地中定位自己和目标？
- 如何做路径规划、动作决策与执行？

重点内容：
- 计算机视觉基础
- 目标检测 / 跟踪 / 位姿估计
- 状态估计 / 定位
- 路径规划
- 决策与控制基础

### 主线 3：多机器人协作与机器人足球场景系统设计

核心问题：
- 多机器人如何分工、协作与通信？
- 机器人足球有哪些典型子问题？
- 如何从 toy system 逐步走向更真实的 team-level system？

重点内容：
- 多智能体系统基础
- 协作与角色分工
- 比赛状态建模
- 队形 / 战术 / 通信 / 同步
- 仿真中的 team-level evaluation

### 主线 4：语言智能 / 多模态智能 / 支撑 Infra（语言智能子能力线）

核心问题：
- 机器人需要哪些语言智能 / 多模态智能能力？
- 这些能力如何与感知、规划、控制衔接？
- 让它们在具身系统中跑起来、跑得稳，需要哪些 AI Infra 能力？

重点内容：
- LLM / 多模态基础：token / embedding / attention / generate / KV cache
- 训练直觉：micrograd → makemore → nanoGPT 一条主线
- 推理与 serving：inference / serving / runtime / agent runtime
- 工程化：profiling / benchmark / GPU / memory / latency / observability
- 在具身系统中的角色：自然语言指令理解、高层任务分解、多机器人语言协调

## 2026 年的阶段目标

目标：
- 完成知识库目标升级
- 形成第一版“机器人足球 / 具身智能 / AI Infra”总图

## Phase 2：短期 LLM 主线延续 + 机器人系统基础入门（2026-05 ~ 2026-08）

目标：
- 短期继续以 `nanoGPT / GPT fundamentals / inference basics` 建立 AI 系统整体感
- 中期逐步引入机器人系统、CV、控制、ROS2 与仿真基础
- 形成 `机器人 + CV + LLM` 并存的稳定学习结构，避免完全断掉 AI Infra 主线

阶段产出：
- `nanoGPT / GPT fundamentals` 阶段总结
- 机器人系统基础笔记
- 机器人足球问题拆解文档
- 仿真/软件栈第一轮理解
- AI Infra 支撑线阶段笔记

## Phase 3：围绕机器人足球做第一轮场景化聚焦（2026-09 ~ 2026-12）

目标：
- 把抽象学习逐步拉回“机器人足球”场景
- 明确第一批可落地的小实验或仿真任务
- 逐步判断后续要更偏机器人软件、感知决策还是 embodied AI system integration

阶段产出：
- 机器人足球子问题列表
- 一个最小仿真/系统设计闭环说明
- 第一轮实验计划
- 年末复盘与下一年度方向判断

## 当前阶段判断

你现在不应该把自己定义成：
- “只学 vLLM / sglang / inference 的人”

而应该定义成：
- “以机器人足球为长期目标，当前正在从 AI Infra 出发，扩展到具身智能系统学习的人”

这意味着：
- 之前的 AI Infra 积累没有作废。
- 但后续所有阅读、笔记、计划与实验，都要开始回答一个更大的问题：
  - `它和机器人足球 / 具身智能系统的关系是什么？`

## 今年最重要的判断标准

到 2026 年底，如果下面这些点基本成立，说明这次转向是成功的：

- 你已经不再把自己局限为“只学 serving 框架的人”。
- 你已经形成一张具身智能 / 机器人足球 / AI Infra 的统一地图。
- 你知道未来 1-2 年最值得投入的能力模块是什么。
- 你保住了 AI Infra 这条有区分度的能力线，同时把它放进了更大的系统目标里。
- 你的知识库已经从“LLM 学习仓库”升级成“具身智能 + AI Infra 长期成长系统”。

## 当前执行原则

- 不推翻已有知识库结构，优先做目标升级与语义重组。
- 不完全放弃 LLM inference / AI infra，而是调整其优先级与定位。
- 所有后续学习内容，都尽量回答一个问题：
  - `它如何服务于未来的机器人足球 / 具身智能目标？`
- 先建立系统地图，再进入具体技术深挖。
- 先收敛主线，再决定具体实验点与工程实现路线。
