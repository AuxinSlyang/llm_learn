# 学习路线图（升级版）

## 目标重定义

### 终极目标
- 构建一支属于自己的机器人足球队。

### 长期能力目标
- 成长为一名能够打通机器人系统、感知决策、多机器人协作与 AI Infra 的具身智能系统构建者。

### 对 AI / LLM / Inference 的定位（2026-05-17 更新）
- 具身智能由多种「智能子能力」组成：感知 / 运动 / 决策 / **语言** / 协作。
- `LLM / 多模态` 是机器人**语言智能子能力**本身，不是外挂支撑。
- `AI Infra`（inference / serving / runtime / GPU / profiling）是让语言智能在机器人系统中跑得起来、跑得稳的工程化能力。
- 学习 LLM 不是为了独立的 LLM 工程师身份，而是为了让机器人具备语言层智能。

---

## 学习主线

### 主线 A：机器人与具身智能基础
目标：建立机器人系统总图，理解机器人足球需要哪些基础模块。

重点：
- 机器人学基础
- 机器人软件栈
- ROS2 / 仿真环境
- 单机器人与多机器人系统结构
- 机器人足球问题拆解

### 主线 B：感知 / 定位 / 规划 / 控制
目标：建立机器人闭环中的核心技术地图。

重点：
- 视觉感知
- 检测 / 跟踪 / 位姿估计
- 定位与状态估计
- 路径规划
- 决策与控制

### 主线 C：多机器人协作与足球场景系统设计
目标：把学习拉回真实场景，理解 team-level system。

重点：
- 多智能体协作
- 通信与角色分工
- 比赛状态理解
- 战术与系统集成
- 场景化实验设计

### 主线 D：语言智能 / 多模态智能 / 支撑 Infra
目标：把 LLM / 多模态模型作为机器人语言智能子能力来学，并补全让它跑得起来的工程能力。

重点：
- LLM / 多模态基础：token / embedding / attention / generate / KV cache
- 训练直觉：micrograd → makemore → nanoGPT
- 推理与 serving：inference / serving / runtime / agent runtime
- 工程化：profiling / benchmark / GPU / memory / latency / observability
- 在具身系统中的角色：自然语言指令、高层任务分解、多机器人语言协调

- “以机器人足球为长期目标，当前正在搭建具身智能总图，并保留 AI Infra 为长期支撑能力的学习体系”

## 判断一条内容值不值得学的新标准

以后看一个主题、课程、项目、框架时，优先问：

1. 它属于机器人足球系统的哪个模块？
2. 它是在补机器人闭环，还是补 AI Infra 支撑能力？
3. 它是当前阶段最短板，还是只是“看起来高级”？
4. 它最终能不能沉淀成长期复用的知识或实验资产？
