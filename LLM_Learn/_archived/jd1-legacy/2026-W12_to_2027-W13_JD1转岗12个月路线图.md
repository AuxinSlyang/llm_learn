# 2026-W12 ~ 2027-W13 学习路线图（升级版）

## 目标定义

新的目标不再是单一对齐某个 `LLM Inference / Serving` 岗位，而是对齐下面这组长期能力：

- 机器人系统理解
- 感知 / 定位 / 规划 / 控制的最小地图
- 多机器人协作与机器人足球场景建模
- 仿真到实验的系统闭环
- AI / LLM 推理基础设施作为支撑能力

## 两个时间点

### 时间点 A：2026-08 ~ 2026-10

目标：`完成从单一 LLM 路线到具身智能总图的切换，并形成第一版稳定学习框架`

最低标准：
- [ ] 有一份稳定的具身智能 / 机器人足球 / AI Infra 学习地图
- [ ] 能讲清机器人足球系统至少包含哪些模块
- [ ] 有机器人系统基础、感知链路、规划控制基础的第一轮笔记
- [ ] AI Infra 主线没有断，且重新找到了新的定位

### 时间点 B：2026-12 ~ 2027-04

目标：`形成更明确的聚焦方向，并为第一轮场景化实验做准备`

最低标准：
- [ ] 对自己更偏机器人软件、感知决策、还是 embodied AI system integration 有了判断
- [ ] 有第一轮面向机器人足球场景的问题拆解与实验方向
- [ ] 有一套能持续推进的月/周/日学习与实验沉淀节奏

## 整体分期

### Phase 1：目标升级与总图建立（W17 ~ W21）

目标：`把知识库与学习叙事从 LLM-only 切到 embodied + AI infra`

### Phase 2：机器人系统基础入门（W22 ~ W35）

目标：`建立机器人系统、仿真、感知、规划控制的最小地图`

### Phase 3：场景化聚焦与第一轮实验设计（W36 ~ W52）

目标：`围绕机器人足球做问题拆解，逐步形成实验方向`

### Phase 4：2027 Q1 深化与方向判断（W01 ~ W13）

目标：`判断下一阶段是更偏机器人软件、感知决策，还是 embodied AI + infra integration`

## 当前最重要的变化

你当前的学习身份从：
- `LLM Inference / Serving 学习者`

升级为：
- `以机器人足球为长期目标的具身智能系统学习者，并保留 AI Infra 作为关键支撑能力`

## 执行原则

- 不推翻已有结构，优先重写目标与语义。
- 不把过去的 inference 学习资产当作无效投入。
- 新的所有月计划、周计划、阅读与实验，都要尽量回答：
  - `它属于机器人系统的哪一层？`
  - `它是在补主线还是补支撑能力？`
- 先建立地图，再逐步聚焦。
