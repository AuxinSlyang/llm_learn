## 今日论文 takeaway

- `Diffusion Policy` 是 action generation 的现实桥：把生成式 diffusion 的去噪直觉落到 robot policy，核心对象从 image sample 变成 future action sequence。
- `Flow Matching` 是理解 pi0 的关键支撑：与其只记 flow matching 公式，不如先抓 `conditioned vector field` 如何把 noisy action chunk 推向 demonstration action chunk。
- `pi0-FAST` 提醒 action representation 有两条分叉：一条是 continuous action chunk / flow action expert，另一条是 action tokenization / autoregressive prediction。
- Systems / causal 支撑线的共同提醒：robot runtime 不能只看模型输出，还要保留 lease/fencing、latency、watchdog、attribution 和可验证 failure evidence。
