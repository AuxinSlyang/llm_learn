    - `LeNet`：CNN 基本语法成立，局部感受野 / 权重共享 / pooling / 端到端视觉分类。

## 今日总结

- 今天最重要的收获：
  - 已经把 `CNN backbone -> visual tokens -> image-text alignment -> image-to-LLM connector -> visual instruction tuning` 这条线讲清楚。
  - 可以用一句主线概括今天的学习：

```text
LeNet/AlexNet/VGG/ResNet: image -> visual backbone
ViT: image -> patch tokens
CLIP: image/text embeddings alignment
BLIP-2: visual embeddings -> LLM-readable visual prompt
LLaVA: image + instruction -> assistant text
```

- 今日论文 takeaway：
  - `ResNet`：`F(x)+x` 解决 deep plain net 的 optimization/degradation 问题，不只是防止梯度爆炸。
  - `ViT`：patchify + linear projection + class token + position embedding + Transformer encoder，把图像转成 token sequence。
  - `CLIP`：用 contrastive loss 做开放语义空间的 image-text alignment。
  - `BLIP-2`：Q-Former 是 connector / visual query bottleneck，不是直接生成可读 caption；它生成 language-aligned visual embeddings。
  - `LLaVA`：核心是 projector + visual instruction tuning，让 VLM 从 caption/VQA 走向 assistant-style response。
