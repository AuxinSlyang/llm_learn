## CLIP 当前理解

```text
image -> ResNet / ViT -> image embedding
text  -> Transformer -> text embedding
similarity = image_embeddings @ text_embeddings.T
```

- batch 内 `N` 个图文 pair 形成 `N x N` 相似度矩阵。
- 对角线是真实匹配，非对角线是负样本。
- 训练目标是让匹配图文靠近，不匹配图文远离。
