## 今日总结

- 今天最重要的收获：理解 DPO 不是普通 SFT，也不是 PPO/RL，而是把 RLHF 的 `显式 reward model + PPO/RL policy optimization` 重参数化为 `reference-anchored pairwise log-prob loss`。
- 今日论文 takeaway：
  - `DPO`：用 `chosen/rejected` preference pairs 直接训练 policy，让 `r_hat_θ(x, chosen) > r_hat_θ(x, rejected)`；其中 `r_hat_θ(x, y)=β * log(π_θ(y|x)/π_ref(y|x))` 是由当前模型相对 reference model 的概率比定义出的隐式 reward。
  - `Self-Consistency`：它不是训练方法，而是 inference-time decoding strategy；用 `多条 CoT 路径采样 -> final answer voting` 替代单条 greedy CoT，让模型选择自身多次推理中最一致的答案。
  - `ReAct`：它不是复杂训练算法，而是 `prompt protocol + runtime loop`；用 `Thought -> Action -> Observation` 把 CoT 推理接到外部工具/环境反馈上，适合作为高层 agent/runtime 范式。
- 今天最大的阻塞：PPO/RLHF、KL constraint、reference model、implicit reward 和 DPO loss 的关系一开始容易混；已拆清楚：`π_ref` 冻结只作 baseline，梯度只更新 `π_θ`，DPO 没有硬阈值，主要靠 sigmoid 饱和梯度、`β` 和训练监控降低过优化风险。
- 今天方向修订：论文线今天超额完成 3 篇；tokenizer / nanoGPT 主链路未现场收口，用户会异步继续看 tokenizer 视频，明天必须把 tokenizer 完整压成可复述笔记。
