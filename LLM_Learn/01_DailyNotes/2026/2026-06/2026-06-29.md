### 今日论文 takeaway

- DeepSeek-V2 的核心不是单纯 MoE 扩参，而是 model-systems co-design：MLA 在 attention 侧把 full K/V cache 改成 `compressed latent KV + decoupled RoPE key`，从源头降低 decode 阶段的 cache footprint 和 memory bandwidth；DeepSeekMoE 在 FFN 侧用 routed/shared experts 降低每 token 激活计算，但把问题转成 routing、load balance 和 communication efficiency。
- 对 AI Core Storage 路线的启发：KVCache Storage 不能孤立设计，必须同时看模型结构、量化、scheduler、offload/tiering 和 prefix reuse；模型侧若已把 KV footprint 大幅压缩，系统侧重点会从“放得下”转向 tail latency、复用、调度和多租户隔离。
