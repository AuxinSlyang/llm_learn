- 模型：`候选：Qwen2.5-1.5B-Instruct / Llama-3.2-1B-Instruct`

- 指标：`GPU 型号 / 显存 / 驱动 / CUDA / Python / zsh / 虚拟环境可用性`
- 观察：
  - `nvidia-smi` 确认 GPU 为 `Tesla V100-SXM2`，显存 `32510 MiB`，当前空闲无进程占用。
  - 驱动版本为 `470.129.06`，驱动显示兼容 `CUDA 11.4`。
  - 初始状态下 `nvcc` 不可用，排查后确认机器存在 `/usr/local/cuda` 与 `/usr/local/cuda-11.4`，问题是 `PATH` 未配置。
  - 修复 `CUDA_HOME`、`PATH`、`LD_LIBRARY_PATH` 后，`nvcc --version` 正常，版本为 `11.4.48`。
  - 系统默认 `python3` 为 `/bin/python3`，版本 `3.7.3`，且缺少 `pip` 与 `ensurepip`，不适合作为实验主环境。
  - 通过 Linuxbrew 使用 `python3.10`，成功创建虚拟环境 `~/venvs/llm-infer`。
  - 激活 `llm-infer` 后，`python` 为 `3.10.19`，`pip` 正常可用，后续可直接用于安装 PyTorch 与 `transformers`。
  - `.zshrc` 已完成基础整理，`llm` alias 可直接激活实验环境。
