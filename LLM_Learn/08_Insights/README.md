# Insights

这里用于收纳 **高价值、可长期复用** 的学习沉淀，而不是日常日志或临时碎片。

## 适合放什么

- 高质量学习总结
- 关键概念解释
- 阶段性 insight
- 路线修正后的结论
- 精加工参考材料（如高质量译文、系统性摘要）
- 对长期目标有帮助、值得回看和复用的内容

## 不适合放什么

- Daily 日志
- 当天临时碎片
- 未整理的阅读摘抄
- 纯过程型实验流水账
- 低复用、还没想清楚的半成品

## 当前建议

- 能进入 `08_Insights/` 的内容，默认应该已经经过一次整理、提炼或重写
- 如果某条内容只是“今天看到一点东西”，优先写在 Daily Note；如果经过整理后有长期价值，再转入这里
- 后续可按 `年 / 月` 继续细分，但当前先保持轻量
- `Systems/` 用于收纳可迁移的系统思考：经典存储 / 分布式系统 / 分布式计算如何回接 AI Infra、Robot Runtime 和数据闭环
