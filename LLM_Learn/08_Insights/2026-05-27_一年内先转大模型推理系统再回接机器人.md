# 一年内先转大模型推理系统，再回接机器人

日期：2026-05-27

## 结论

未来一年主线调整为：

> 短期优先转向 `LLM Inference Infra / vLLM 推理系统`，积累真实模型 serving、GPU、调度、性能优化和可靠性经验；中长期再把这套能力迁移到 `VLA runtime / policy runtime / robot learning infra`，继续服务具身智能 / 机器人系统目标。

## 为什么这个调整更平滑

- 当前 DB / 存储 / 系统工程背景更容易迁移到高并发、资源管理、调度、性能优化和可靠性问题。
- 大模型推理岗位比纯机器人学习岗位更接近当前履历，短期职业可行性更高。
- vLLM / SGLang / TensorRT-LLM / GPU profiling 能形成更清晰的工作经验和面试证据。
- 机器人长期也会需要 VLA / LLM / policy runtime，不会浪费这条能力线。

## 新路径

```text
DB / Storage Kernel
-> LLM Inference Infra / vLLM / Serving / GPU Profiling
-> VLA Runtime / Robot Policy Runtime / Edge-Cloud Inference
-> Robot Learning Infra / Robot System / Multi-Robot Coordination
-> Embodied AI / Robot Systems
```

## 边界

- 推理系统是未来一年的主线，不是永久终点。
- 千卡训练系统只保留 awareness，不作为第一阶段主项目。
- 机器人学习不急着硬上，但不能从路线里消失。
- 到 2027 H2，需要开始把推理能力明确回接到机器人 runtime / VLA / policy inference。

## 2027-03 时间节点

把 2027-03 设为第一轮职业转向硬检查点。

含义：

- 不是到 2027-03 才开始学推理系统，而是从现在开始推进，到 2027-03 做第一次职业可行性验收。
- 到 2027-03，需要具备强候选人的基础证据：`LLM inference mini-stack`、JD mapping、面试 Q&A、benchmark / profiling 记录。
- 如果当前主业阶段性收口，2027-03 开始可以更认真做内部 / 外部 AI Inference Infra 机会测试。
- 如果 2027-03 作品还不够强，2027-Q2 继续补作品和面试材料，而不是盲目跳。

## 对现有路线的影响

- `Modern Robotics / MuJoCo / LeRobot / Robot Learning` 从 2026 H2 主线后移为中长期主线。
- `nanoGPT -> inference runtime` 成为 2026-06 的关键桥接。
- 未来一年核心作品从 `Embodied AI mini-stack` 调整为 `LLM inference mini-stack`。
- 机器人方向保留为 North Star，不再作为未来一年转岗的第一跳。
