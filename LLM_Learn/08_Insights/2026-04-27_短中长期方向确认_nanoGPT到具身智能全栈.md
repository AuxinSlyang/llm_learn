# 短中长期方向确认：从 nanoGPT 到具身智能全栈

## 本次确认的核心结论

### 短期目标
- 本周主线是 `nanoGPT`
- 五一期间继续保持 `nanoGPT` 主线
- 短期仍然以 `LLM 相关内容` 为主，因为它能帮助快速建立模型、训练、推理与系统整体感

### 中长期目标
- 后续不再只着眼于 LLM
- 学习结构升级为：`机器人 + CV + LLM` 并存
- 长期方向明确为：朝 `具身智能全栈工程师` 方向发展

## 为什么这个结构合理

这条路径兼顾了两件事：

1. `短期效率`
   先用 `nanoGPT / LLM fundamentals` 快速建立 AI 系统直觉，降低后面看 inference / serving / agent / multimodal system 的理解门槛。

2. `长期目标一致性`
   未来真正的目标是具身智能与机器人系统，所以必须逐步补上：
   - 计算机视觉
   - 感知链路
   - 控制 / 规划
   - 机器人软件栈
   - 仿真与系统集成

## 新的一句话定位

> 短期先用 `nanoGPT` 补 LLM / GPT / 训练代码直觉；中长期逐步转向 `机器人 + CV + LLM` 并存的学习结构，整体朝 `具身智能全栈工程师` 方向前进。
