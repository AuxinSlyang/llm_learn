# start-my-day spec summary

Intent:
- Read yesterday, this week, this month, and annual context
- Generate today's learning/execution plan
- Prefer updating today's Daily Note

Default outputs:
- 今日主题
- 今日 Top 3
- 今日时间切片
- 今日最低完成线
- 今日建议阅读
- 今日不要做什么
- 明天承接点

Current practical bias:
- Minimum completion line first
- Recommended execution order second
- Top 3 and time slicing third
- Concrete commands/files when useful

Current workspace emphasis:
- LLM Inference / Serving
- Prefer one main line plus at most two supporting tasks
- Do not waste tokens on broad summaries of all notes
